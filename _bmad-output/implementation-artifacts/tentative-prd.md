# Event Company Website - PRD Rough Draft

## Project Overview
Website for an event company that produces and promotes:
- Hip-hop events
- EDM events
- Fashion shows

## Target Audience
**Primary Demographic: Ages 21-24**
- Recent graduates and early-career professionals
- College students (upperclassmen and recent grads)
- Emerging artists and creators in hip-hop, EDM, and fashion
- Social media natives (Instagram, TikTok, Snapchat)
- Price-conscious but value experiences and authenticity
- Community-oriented, seeking connection and belonging

**Audience Segments:**
- **Event Attendees (21-24):** Ticket buyers who prioritize authentic experiences, community connection, and social sharing
- **Emerging Artists/Performers (21-24):** Early-career talent looking for platforms and opportunities
- **Fashion Designers (21-24):** Emerging designers and style creators building their brands
- **Vendors/Sponsors:** Brands targeting the Gen Z/early millennial demographic

## Core Business Goals
- Increase event ticket sales
- Build brand awareness and community
- Streamline event promotion and management
- Attract sponsors and partners

## Key Features & Functionality

### Event Discovery & Ticketing
- Browse upcoming events (hip-hop, EDM, fashion shows)
- Event listing page with category filtering
- Individual event detail pages with:
  - Event images/gallery
  - Complete event information (date, venue, lineup, description, schedule)
  - Link to ticket sales (internal ticket system - tentative)
- Past events gallery

### Content & Engagement
- Photo/video galleries from past events
- Live video streaming integration for events (live feed during events)
- Email newsletter signup
- Social sharing capabilities for events

### Navigation & User Experience
- Clear navigation between pages (Home, Events, About, Contact)
- Mobile-responsive design
- Fast page loading
- Easy ticket purchasing flow (via internal system - tentative)

## Brand & Experience
- Urban, energetic, modern aesthetic
- Mobile-first design (critical for 21-24 demographic who primarily use phones)
- Fast loading, optimized for social media sharing (Instagram, TikTok, Snapchat)
- Accessible and inclusive
- Authentic, community-driven voice (resonates with Gen Z/early millennial values)
- Visual-heavy content optimized for social sharing

## Technical Stack & Architecture
- **Frontend:** Vanilla HTML, CSS, and JavaScript (no frameworks)
- **Style:** Custom CSS with mobile-first responsive design
- **Interactivity:** Vanilla JavaScript for dynamic features
- **Ticketing:** Internal ticket sales system (tentative plans for future development)
- **Video Streaming:** Live event feed integration (via third-party streaming platform API/embed - e.g., YouTube Live, Twitch, Vimeo Live, or custom streaming service)
- **Integration:** Social media links and sharing
- **SEO:** Optimized HTML structure for event discovery
- **Performance:** Fast loading, optimized images and assets, optimized video streaming for mobile

## Target Audience Considerations (Ages 21-24)

**Key Demographic Insights:**
- **Digital Natives:** Heavy use of mobile devices, Instagram, TikTok, Snapchat
- **Price Sensitivity:** Budget-conscious but willing to pay for authentic experiences
- **Social Sharing:** Events are social experiences - emphasis on shareable content and FOMO
- **Authenticity-Driven:** Values genuine experiences over corporate polish
- **Peer Influence:** Strong influence from friends, influencers, and community recommendations
- **Early Career Stage:** Building identity, networking, seeking opportunities
- **Community-Oriented:** Looking for belonging and connection with like-minded people

**Content & Design Implications:**
- Mobile-first is absolutely critical (this demographic primarily uses phones)
- Strong visual content (photos, videos) for social sharing
- Clear pricing and value proposition (budget-conscious)
- Emphasis on community and peer connections
- Authentic, unfiltered brand voice (not overly corporate)
- Easy social sharing features
- Quick decision-making support (clear CTAs, simple navigation)

## Notes
- Company produces multiple event types - need clear categorization
- Strong visual identity important for hip-hop/EDM/fashion audience (especially for 21-24 demographic)
- Mobile experience is absolutely critical - this age group primarily uses mobile devices
- Social proof and FOMO (fear of missing out) are key conversion drivers for this demographic
- Live streaming adds value for remote audience and extends event reach (important for 21-24 demographic who value accessibility and shareability)
- Authenticity and community connection are paramount - avoid corporate tone
- Starting with simple vanilla HTML/CSS/JS stack for easier maintenance and faster initial development
- Video streaming will require third-party service integration (embedded players work well with vanilla JS)
- Internal ticketing system is a future enhancement - initial focus is on core website pages and streaming
- Existing webpage content files available for reference (home, about, events, contact, event detail pages)
